# 野牛格

一款為手機設計的繁體中文牧場邏輯益智遊戲。每一列、每一欄與每個彩色牧區都必須剛好放一頭牛，而且牛不能彼此相鄰（斜角也不行）。

## 遊玩

- 點一下格子：放排除記號
- 再點一下：放牛
- 第三下：清除
- 主介面可選「牧場旅程」與「無盡模式」，並繼續上次作答
- 牧場旅程：10 大關 × 20 題，固定題庫、循序解鎖，完成題可重玩
- 棋盤從 5×5 到 9×9，推理技巧由單一位置、交叉排除進階到多牧區組合
- 10 套章節配色與原創淡線稿背景，放牛不會改變格子尺寸
- 提示先解釋理由，再選擇套用；用提示仍可過關，無提示完成會留下星號
- 保留無盡模式，左上題號可直接選關；支援復原、計時與裝置端進度保存
- 首次更新自動轉入舊版無盡存檔，保留原儲存鍵；主介面可匯出／匯入 JSON 備份
- 每一關都會由內建解題器驗證只有一個答案後才顯示
- 可在 Android Chrome 使用「加到主畫面」安裝，並支援離線遊玩

## 開發

```bash
npm install
npm run dev
npm test
```

## GitHub Pages

專案已包含 `.github/workflows/deploy-pages.yml`。在 repo 的 **Settings → Pages → Build and deployment** 將 Source 設為 **GitHub Actions**，之後推送到 `main` 就會自動發布。

本專案的名稱、介面與美術均為原創；玩法採用常見的區域配置邏輯規則，未使用 Bullpen 的程式、商標或美術素材。

## 題庫與存檔版本

`lib/campaign-data.ts` 是已凍結的 200 題 v1 題庫。離線候選產生器先驗證唯一解、區域連通與人類推理規則，再分技巧級別與推理負擔排序，並排除旋轉／鏡射重複題。所有題目都有不需猜測的逐步推理證明；這是程式分級，實際體感仍可透過玩家回饋調整。不要重新產生後覆蓋已發布的同一批 ID；未來改題必須升級內容 ID 並處理存檔遷移。

進度只存在目前瀏覽器，不同網域（GitHub Pages、Sites、本機）、裝置不會自動同步。清除網站資料或無痕瀏覽可能讓存檔消失；請使用匯出／匯入備份。匯入採合併，保留本機作答及兩份存檔的完成紀錄。

章節背景以內建 Imagegen 生成並轉為 WebP，原始提示記錄在 `public/chapters/art-prompts.json`。兩隻牛困難模式尚未加入。
